# Radiologist Aid for Pneumonia Detection using Deep Learning

AI-based system for detecting pneumonia from chest X-ray images using deep learning.  
Implements a CNN model with Python and TensorFlow/Keras to assist radiologists in accurate and early diagnosis.

## Features
- Automated pneumonia detection from chest X-ray images
- Deep learning-based image classification
- Image preprocessing and augmentation
- Model training and evaluation

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
